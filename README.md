# splitmate

A static web project in its early stages. Right now the repository contains a single  
HTML page — the scaffolding that the rest of the app will be built on.

## Status

Early / scaffolding. There is no build step, no dependencies, and no **application**  
logic yet. [index.html](index.html) is a plain "Hello, World!" document.

## Project structure

```
.
├── index.html    # the entry page
├── .gitignore
└── README.md
```

`.sf/` may appear locally — it is Salesforce CLI cache generated by tooling and is  
ignored by git.

## Running locally

Because there is no build step, open the page directly:

```bash
open index.html
```

Or serve it over HTTP, which is closer to how it will run in production:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

Any static file server works — `npx serve`, `php -S localhost:8000`, and so on.
